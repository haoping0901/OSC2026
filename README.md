# OSC 2026

## Environment Setup

### Cross Compiler

```bash
sudo apt update && sudo apt install gcc-riscv64-unknown-elf
```

### QEMU

```bash
sudo apt update && sudo apt install qemu-system-riscv64 opensbi u-boot-qemu
```

### Bootloader Tools

```bash
sudo apt update && sudo apt install u-boot-tools
```
